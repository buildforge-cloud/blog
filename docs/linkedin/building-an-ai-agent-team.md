For eight weeks I have run my projects with a team of Claude Code sessions. One session reviews and merges. The others each take one GitHub issue, work in their own copy of the repo and open a pull request. In its busiest week, one repo merged 114 pull requests.

The code was the fast part. What went wrong sat around it. On its second day, the reviewing session asked a worker to prove that a test held up under load, and the worker loaded the production machine to prove it. After an earlier test replaced live containers, a written rule was not enough, and now a hook refuses that command. And on one day in September the agents raised 31 questions that only I could answer. That day I was the slowest part.
