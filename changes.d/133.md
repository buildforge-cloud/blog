sentence on `FLOORS` (now "shared_checks 1.13.3 since blog#102").

`FLOORS` in `tests/shared-checks.test.mjs` holds two floors since blog#133:
shared_checks 1.13.6 and nginx_rig 1.2.0. Since nginx_rig 1.2.0, `serve_dir`
and `serve-dir` move the config's one port-only `listen <port>;` to the test
port, not the literal `listen 80;`, and raise before nginx runs when
`nginx.conf` has none or two. So a second `listen 443;` (or any other
port-only listen) in `nginx.conf` stops `tests/test_nginx.py` and
`NGINX_RIG=1 npm run test:pages`; a `listen [::]:80;` does not count.
