For CLAUDE.md, "Writing a post", after the paragraph on `og-image-date.spec.mjs`:

`npm run test:pages` never opens a queued post: the production build it
serves leaves a future-dated post out, so its contrast and CSP are not
measured until the morning it goes live. To measure one before merge, set its
`pubDatetime` to a past time, `npm run build`, run `npx playwright test`, then
put the queued date back (blog#92 did this for two posts; a plain code block
and inline code passed).
