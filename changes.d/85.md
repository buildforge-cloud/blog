`ci.yml` also runs on a push to `main` (blog#85), so the Playwright browser
cache is saved where every pull request can read it. It caches
`~/.cache/ms-playwright`, keyed on the runner image (`$ImageOS`, read in a
step: `${{ env.ImageOS }}` is always empty) and the `@playwright/test`
version in `package-lock.json`, and runs `playwright install --with-deps`
(apt-get) only on a miss. Restore, install and save are separate steps with
a 3-minute bound each; a stalled restore falls through to the install. A
Playwright upgrade or a new runner image misses once.
