Fold into CLAUDE.md, "Deployment", the paragraph "`ci.yml` installs Chromium
after the build":

`ci.yml` gets the browser without apt-get (blog#85). It restores
`~/.cache/ms-playwright`, keyed on the runner image (`$ImageOS`, read in a
step: `${{ env.ImageOS }}` is always empty) and the `@playwright/test`
version in `package-lock.json`. On a miss `npx playwright install chromium`
downloads the browser alone, and `scripts/browser-libs.mjs` runs `ldd` on it:
`playwright install-deps` (apt-get) runs only when a library is missing.
Each step has a 3-minute bound, and a stalled restore falls through to the
download. The save runs after `npm run test:pages`. `ci.yml` also runs on a push to `main`, so the cache is saved where
every pull request can read it.
