`ci.yml` also runs on a push to `main` (blog#85), so the Playwright browser
cache is saved where every pull request can read it. It caches
`~/.cache/ms-playwright`, keyed on the `@playwright/test` version in
`package-lock.json`, and runs `playwright install --with-deps` (apt-get) only
on a miss; the restore and the install each have a 3-minute bound. A
Playwright upgrade misses once, on its own PR and on `main`.
