# For CLAUDE.md (AGENTS.md), from blog#145

1. **Development, "astro is pinned at exactly 7.2.9 for now (blog#83)".**
   No longer true. Since blog#145 astro is `^7.4.13` beside `@astrojs/mdx` 8,
   which lifted the cap. `tests/packages.test.mjs`'s pin check only binds
   again if mdx goes back to 7. Keep the warning against `--force`. Its
   advisory list now holds astro at 7.4.7, satori at 0.33.5 and fflate at
   0.7.5. satori 0.63 pins fflate 0.7.3 (GHSA-px8p-9vwx-vf98), so
   `package.json` has the repo's first `overrides` entry, satori's fflate at
   0.7.5. A test there fails once satori asks for anything but a vulnerable
   exact fflate: then the override goes.

2. **Deployment, Dependabot paragraph, "Two ignores exist".** Still two, but
   not the same two. The astro ignore is gone: `tests/dependabot.test.mjs`
   fails if it comes back while mdx is on 8. In its place is TypeScript 7
   (`>= 7`). TS 7 has dropped the classic JS API, and `@astrojs/check` (peer
   `^5 || ^6`), `@typescript-eslint/parser` (peer `<6.1.0`) and
   `@volar/*` (`<7`) need it, so in the majors group it would turn the whole
   PR red at `npm install`. The test reads every locked `typescript` peer
   range with a small range reader, which throws on a form it cannot read.
   It fails once none refuses 7.0.2, and then the ignore goes. node 23 and 25
   stay held as before.

3. **New, beside "Comments (giscus)"'s note on `features.dynamicOgImage`.**
   satori 0.63 paints and sizes boxes like a browser, where 0.26 did not. The
   share images (`src/pages/og.png.ts`, `src/pages/posts/[...slug]/index.png.ts`)
   and the LinkedIn cover keep their look only with `position: relative` on
   the card (else its absolute shadow is painted over it),
   `boxSizing: border-box` on both boxes, and an explicit margin on each
   `<p>`. A satori bump can break them while the build stays green, so the
   pixels are checked: `tests/og-image-render.spec.mjs` (in
   `npm run test:pages`) and `tests/linkedin-cover.test.mjs` (in `npm test`).
   A deliberate layout change moves their constants (the card's top edge at
   y 63 and y 108).

4. **"A LinkedIn Article", the cover.** `node scripts/linkedin-cover.mjs
   <slug>` is unchanged for the user. The drawing is now `drawCover(headline)`
   in `scripts/linkedin-cover-draw.mjs`, which the test calls. The command
   line file has no run-as-script guard: one that compared `process.argv[1]`
   with `import.meta.url` exited 0 without drawing when the path held a
   symlink. The test runs it through one.
