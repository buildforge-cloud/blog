# Issue #19 -- for CLAUDE.md

Target: `AGENTS.md` (`CLAUDE.md` is a symlink to it), section "Deployment",
after the paragraph that starts "`npm test` (every `tests/*.test.mjs`".

Add:

    **Shared parts (blog#19).** `scripts/shared_checks.py`,
    `tests/css_tokens.py`, `tests/nginx_rig.py` and `tools/psi.py` are
    buildforge-starter releases, pinned byte for byte in
    `scripts/shared-checks.lock`. Never edit one here: `npm test` runs the pin
    tool and fails on a hand edit. Take a fix with
    `python3 scripts/shared_checks.py update <name> <version>`.
    `tests/css-tokens.test.mjs` checks every `var()` in `src/styles/*.css` and
    in the `<style>` blocks and backtick strings of `src/**/*.astro`. It does
    not see a `var()` inside a quoted attribute (`style="..."`, `class="..."`)
    or a Tailwind `-(--name)` class, so put a token use in a `<style>` block
    if it should be checked. A font token Astro sets in `astro.config.ts` is
    named there with `--defined`, so a new font needs a line there too.
    `tests/test_nginx.py` serves the real `nginx.conf` on a real nginx, only
    with `NGINX_RIG=1` (never in CI): run it after any `nginx.conf` change.
    The rig is nginx 1.24, so a directive newer than that (such as
    `add_header_inherit`, 1.29.3) fails `nginx -t` there even where the
    image's nginx takes it.

Keep it to about this length.
