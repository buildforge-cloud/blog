**astro stays on 7.2.x for now (blog#83).** astro 7.2.10 and later want
`@astrojs/markdown-remark` ^7.3, and every `@astrojs/mdx` 7.x pins 7.2.x, so a
newer astro needs `@astrojs/mdx` 8, a major update. Until that is done,
`npm audit fix` stops with ERESOLVE: update a flagged package by name with
`npm update <name>` instead, and never with `--force`.
`tests/packages.test.mjs` (in `npm test`) fails when the lockfile holds a copy
of a package in a range a known advisory names, nested copies included. When
a new critical or high alert is fixed, add its package, range start and fixed
version there.
