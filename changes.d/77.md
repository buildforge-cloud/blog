"The rig's nginx is 1.24":

The rig's nginx comes from the machine's own apt: 1.26.3 on this host (Debian
13, measured 2026-11-07), and it may not match what another machine's apt
offers. A newer directive (such as `add_header_inherit`, 1.29.3) fails
`nginx -t` there even where the image's nginx takes it. A rig run on a filled
`~/.cache/nginx_rig` does not exercise the part's fetch: to test a fetch, run
it with an empty cache (blog#77).
