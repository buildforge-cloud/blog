## 1. "Design — the paper system"

Replace the paragraph that starts "**Contrast has no automated check yet —
that is #6.**" with this one:

    **`npm run test:pages` measures contrast (blog#6).** Playwright walks every
    page in the built sitemap, search with results, and the 404 page, at
    desktop and 390 px. For each run of text it reads the computed colour and
    every background and `opacity` above it, and asserts AA (4.5:1, or 3:1 for
    24px text and 18.67px bold). Build first: it serves `dist/` with
    `astro preview` on 4177. The arithmetic is in `tests/contrast.mjs`, checked
    by `npm test`. A failure is never fixed by the check: it goes in the spec's
    `known` list with its ratio, and Stefan picks the fix. A record covers one
    colour pair on its own pages, and fails the check once the failure is gone.
    Today it holds one: the previous/next post titles (`text-accent/85`,
    3.72:1). Two things pass by rule: a disabled control (WCAG sets no floor;
    the post list's Prev/Next measure 3.27:1), and `::selection`, pinned at
    3.66:1 as the one named exception. Ember `#c2410c` still clears AA by
    0.13; a lighten to `#c5440f` (4.46:1) fails every ember link. Hover
    states are not
    measured. Shiki's `min-light` has three colours under AA that no post uses
    yet (comments 1.75:1, parameters 2.14:1, warn tokens 2.58:1): the first
    post with a code comment will fail the check.

## 3. "Development"

Add after "Building from a worktree":

    Under an AI agent, Astro 7 moves `astro dev` and `astro preview` to a
    detached background server on its own (it detects the agent). A Playwright
    `webServer` then fails with "exited early", and the detached copy keeps the
    port. `playwright.config.mjs` sets `ASTRO_PREVIEW_BACKGROUND=1` for its
    server, which keeps it in the foreground. A worktree needs its own
    `npm install` when its branch adds a package the main checkout does not
    have yet (here `@playwright/test`).
