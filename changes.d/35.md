For CLAUDE.md's "Development" section, beside the worktree Playwright note:

When a worktree run of `npm run test:pages` says Chromium's executable does
not exist, fetch it with `PLAYWRIGHT_SKIP_BROWSER_GC=1` in front of
`playwright install --only-shell chromium`. Without the flag Playwright
deletes every other cached browser version as "unused", and the other
projects on this host download theirs again (blog#28 lost `chromium-1248`
that way; blog#35 kept it with the flag).
