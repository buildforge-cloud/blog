ISO Pathfinder Buddy began in Lovable and moved into its own repo in the
org on 2026-11-10 (that repo's README). Since then it is deployed to
https://iso.buildforge.no, and https://iso-pathfinder-buddy.lovable.app
still answers 200 with the same app shell (checked 2026-11-20).

The blog names only the Lovable host: `about.md` (pinned in
`tests/posts.test.mjs`), the blog-post skill's link list, and the blog#92 and
blog#82 posts. The blog#82 post calls the app ISO 27001 Buddy.

**Why:** Stefan has not said which host is the product's home; blog#82 kept
the Lovable one, the issue's default.

**How to apply:** before a post links the app, check whether Stefan has picked
a host. A change of host means changing all four places at once, as in
[[fleet-domain-moves-grep-whole-repo]].
