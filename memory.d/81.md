Skredda (https://skredda.no) is the private repo `buildforge-cloud/cvtailor`;
its `docs/ENGINEERING_LOG.md` (read with `gh api ... -H "Accept:
application/vnd.github.raw"`) is the source for any post about it, never
linked or copied into the public blog repo.

Stefan's limits (decision 4456, 2026-11-20, blog#81): a Skredda post names
no specific numbers at all (no price, no beta or user counts, no metrics),
and he calls Skredda "a trial of a product I never really fell in love with".
He built it because, as a consultant, he found the many unstructured ways of
bidding with a CV weird, and a post may say he knows the problem himself.

**Why:** the blog's Goal names Skredda, so later posts will cite it again.
**How to apply:** read this before a Skredda post or LinkedIn draft; ask
Stefan before adding any number. See [[blog-post-voice]].
