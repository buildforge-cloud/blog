In the blog repo, `CLAUDE.md` is a symbolic link to `AGENTS.md`. The Edit tool
refuses to write through the link ("it is a symbolic link. Write to the link's
target path instead"), so every CLAUDE.md change, a `changes.d/` fold among
them, is an edit to `AGENTS.md`. Reading `CLAUDE.md` still works.

**Why:** hit while folding `changes.d/66.md` on blog#68 (2026-10-31); the
refused edit costs a call.

**How to apply:** open and edit `AGENTS.md` directly whenever a task says
"CLAUDE.md" in this repo.
