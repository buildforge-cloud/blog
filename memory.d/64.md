To prove `npm run build` makes no network request, run it in a network
namespace: `unshare -rn sh <script>`, where the script runs
`ip link set lo up`, then `cd <worktree>` and `npm run build`. It works on
this host with no root (blog#64, 2026-10-26).

**Why:** the OG image routes (`src/pages/og.png.ts`,
`posts/[...slug]/index.png.ts`) fetch their font file over HTTP from Astro's
own server on `::1` while building. In a bare `unshare -rn` loopback is down,
so `/og.png` fails with `connect EADDRNOTAVAIL`, which looks like a remote
fetch failure and is not one.

**How to apply:** use it for any change that should remove a build-time
fetch. Astro's Google font provider also asks `fonts.google.com` (not only
googleapis/gstatic), so a hosts-file block must name all three.
