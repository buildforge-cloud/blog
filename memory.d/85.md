description: A GitHub Actions cache saved by a pull_request run is readable only by that PR; save it from a run on main to share it

A GitHub Actions cache saved in a `pull_request` run is scoped to
`refs/pull/N/merge`: only that PR's later runs can restore it. A cache saved on
the default branch (`main`) can be restored by every PR. So a workflow that
runs only on `pull_request` never shares a cache between PRs, and each new PR
starts cold. Seen in blog#85 (2026-11-11): every cache in the blog repo was
PR-scoped, so `ci.yml` got a `push: main` trigger to seed the Playwright
browser cache. List the caches and their refs with
`gh api repos/<o>/<r>/actions/caches`.
