A worker session's `gh` token answers `gh api "repos/buildforge-cloud/<repo>/dependabot/alerts?state=open"`
with "Resource not accessible by personal access token (HTTP 403)" (blog#83,
2026-11-11). Only the executive's token, used by agent-orchestrator's `alerts.py`,
can read them. For a package-alert issue, measure before and after with
`npm audit --json` (same GHSA advisories, by the lockfile) and say in the PR that
the alert counts on GitHub are the executive's to confirm after the merge.
