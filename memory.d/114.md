Since 2026-10-08 Stefan's agents (the executive, the workers and their tools) run
on a small server at his home; the live apps run on a rented server (a VPS).
Before that move, agents and apps shared the one rented server, so incidents
from then (the 2026-07-07 outage, the late-September load test) happened on the
rented server.

**Why:** the LinkedIn Article said the agents run "on the same small server that
runs my apps", and Stefan flagged it as untrue (card 4436, blog#114).

**How to apply:** in any post, Article or share text, name which server a
sentence means ("the home server", "the rented server"), and date a shared-server
incident as the past. Ask a cold reader which server each mention means.
