In `buildforge-cloud/blog`, `CLAUDE.md` is a symbolic link to `AGENTS.md`. The
Edit tool refuses to write through the link ("it is a symbolic link"), so a
change to the project rules is an edit of `AGENTS.md`, and `git diff` shows
`AGENTS.md`, not `CLAUDE.md`. Found on blog#53 (2026-10-23).

**Why:** the first Edit of `CLAUDE.md` in a session fails, and a reviewer who
looks for `CLAUDE.md` in the PR's file list finds nothing.

**How to apply:** edit `AGENTS.md` directly. In a PR body, say that the
`CLAUDE.md` rules changed through `AGENTS.md`.
