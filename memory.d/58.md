When a post issue carries a legal guard ("name no source, quote none of its
text", blog#60), the check that proves it holds the forbidden names. This
repo is the org's only public one, so a committed test with that list would
publish exactly what the guard forbids, in the PR, the log and the test.

**Why:** blog#60's guard covered the post, the PR and the log entry alike.

**How to apply:** keep the name list in the scratchpad checker (the blog#42
and #46 pattern), run it and `sanitize.py` before the PR, and in the PR say
only how many names were checked and that none matched. Related:
[[blog-post-sources-and-leak-check]].

- [Legal-guard names stay out of the repo](blog-legal-guard-names-stay-out-of-repo.md) — a post that must not name a source is checked by a scratch list only; a committed list would publish the names.
